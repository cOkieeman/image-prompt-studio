# 共用看图入口

当前对话模型直接观察用户提供的图片，不要求额外服务或 API 密钥。无法访问实际图片时请用户提供图片，不以文件名、EXIF 或原 caption 代替视觉证据。

先区分画面中可见的事实、用户指定的修改、无法确认的内容；再交给所选模型方案写词。观察维度包括主体数量与各自外观、动作和接触、机位和裁切、前中后景、光照方向、配色、材质、表现媒介以及可见文字。不要猜测隐藏部位、器材品牌或不清晰的字符。

## 需要结构化反标时

用户要求“官方标注预设 / JSON caption / 长中短描述”时，读 [官方原始预设](moss-recaptioner.txt)，只输出要求的 JSON。用户只是要图像 prompt 时，将观察结果编译成所选模型的 prompt，不强制额外返回 JSON。

原始 caption 仅是参考；与图片冲突时以可见事实为准。图中文字逐字保留，不翻译或自动纠错。水印只记入 watermark，不混入三个 caption。水印是否被单独标注不会改变图像像素。

## 坐标分流

| 用途 | 坐标 |
|---|---|
| 反标 watermark.box_2d | 全图归一化 0–1000，y_min,x_min,y_max,x_max |
| MOSS 官方 Layout 草稿 | 左上角原点的实际像素，x_min,y_min,x_max,y_max |
| MOSS 编译后 Layout | 画布中心原点的实际像素，y_min,x_min,y_max,x_max |

水印框不是生图布局。生成 MOSS Layout 时重新规划元素框，使用官方编译器转换；不直接把反标 JSON 粘进正面条件。严格复刻应说明文字提示能保留的内容与不确定性，不承诺像素级还原。
